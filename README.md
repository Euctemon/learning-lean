# Learning the Lean language
This repository contains all (or at least I think all) solutions to the problems given in [Theorem proving](https://leanprover.github.io/theorem_proving_in_lean4/title_page.html). I also contains few solutions to problems given in [Functional programming](https://leanprover.github.io/functional_programming_in_lean/title.html). There is nothing special in this repository but it might help someone who struggles with particular problem in the _Theorem proving_ book.
